Park Patrol — offline demo

A guard issues a fine on a phone with no network. The phone is plugged into a laptop with a USB cable, and the ticket, photos and fine appear on the laptop. Nothing uses Wi-Fi or the internet. build {{BUILD}}

1 · Set up the laptop (once)

First unzip the whole package (Windows: right-click the zip → Extract All; Mac: double-click it). Do not start anything from inside the zip.

Windows

  1. Open Laptop - Windows and double-click Start Park Patrol.bat.
  2. If Windows says “Windows protected your PC”: click More info → Run anyway.
  3. A black window opens and the dashboard opens in the browser at http://localhost:4357. Sign in supervisor / Astrikos2026.
  4. Keep the black window open. Close it to stop Park Patrol.
  5. Using an iPhone? Install the Apple Devices app from the Microsoft Store once, while online — it brings the iPhone's USB driver.

macOS

  1. Open Laptop - macOS and double-click Start Park Patrol.command.
  2. The first time, macOS blocks it. macOS 15+: System Settings → Privacy & Security → “Start Park Patrol.command” was blocked → Open Anyway. macOS 14 or older: right-click the file → Open → Open.
  3. Terminal opens and the dashboard opens in the browser at http://localhost:4357. Sign in supervisor / Astrikos2026.
  4. Keep the Terminal window open. Close it to stop Park Patrol.

The laptop works with Wi-Fi off — including the map: a street map of Abu Dhabi is built in. Reset demo data (next to the start file) clears the laptop's tickets, routes and patrol reports for a fresh demo.

2 · Install the app on the phones (once)

Android

  1. Copy Android/ParkPatrol.apk to the phone — e.g. plug it into the laptop, choose File transfer on the phone, and drop the file into Download.
  2. On the phone open Files → Download → tap ParkPatrol.apk. Allow Install unknown apps for Files when asked → Install.
  3. If Google Play Protect warns about an unknown app: More details → Install anyway.
  4. Open Park Patrol, allow Camera and Location, sign in guard1 / Astrikos2026.
  5. Printer: see The fine printer below — pair it once, then choose it in Park Patrol.

The Android app never needs the internet — not even for the first sign-in.

iPhone

Apple only lets iPhones install signed apps, so the iPhone uses the web app. It needs internet once, during setup:

  1. Open Chrome on the iPhone and go to {{IPHONE_URL}} — type it (mind the :8443), or scan this code with Chrome: press and hold the Chrome icon → Scan QR Code.
  2. In Chrome tap Share (the share icon in the address bar, or ⋯ → Share) → Add to Home Screen → Add. Open Park Patrol from the Home Screen.
  3. Sign in once while online: guard1 / Astrikos2026.

From then on it works with no network. The iPhone Camera app opens links in Safari — scan from Chrome instead, or make Chrome the default browser (Settings → Apps → Chrome → Default Browser App). Add to Home Screen from Chrome needs iOS 16.4 or later. The same code and the address are in the iPhone folder.

Optional on both: Settings → GPS source → Demo puts the pins in Abu Dhabi.

The fine printer — NETUM NT-1809 (58 mm, Bluetooth)

  1. Check the printer: load the 58 mm thermal roll (shiny side toward the print head), charge it, then print its self-test page: printer off → hold Feed → switch on → release Feed when the red light comes on. If the print is faint, set density level 3 (printer off → hold Feed → switch on → release when the red light goes on-off-on).
  2. Pair it with the Android phone: Android Settings → Bluetooth → pair the printer. PIN 0000 or 1234.
  3. Choose it in Park Patrol: Settings → Fine printer → Bluetooth printer (direct) → Choose printer → tap the printer. Allow Nearby devices when asked. Paper width: 58 mm. Press Test print.
  4. After that, every new violation offers Print notice; the notice comes out of the printer in a few seconds. One printer talks to one phone at a time — switch it off and on to move it to another phone.

iPhone: this printer has no iPhone app from NETUM and does not support AirPrint, and an iPhone web app cannot use Bluetooth. Print from an Android phone in the demo; on the iPhone use Issue without printing. (A Bluetooth-enabled browser such as Bluefy can work if the printer also offers Bluetooth LE — test before relying on it.)

Patrol routes (optional, 2 minutes once)

  1. On the laptop: Field Team → Patrol routes. Two sample routes are there; New route to draw your own — click the map to place checkpoints in order, choose the guard, days and shift → Save route. The map is built in — it works with no internet.
  2. Press Code for phone on the guard's route — a QR code appears.
  3. On the guard's phone: Patrol tab → Scan route code → point the camera at the laptop screen (or take a photo of it). The route appears on the phone's offline map.

3 · The demo (about 5 minutes)

#DoShow / say
1Laptop Wi-Fi off. Phone in airplane mode.“No network anywhere.”
2Phone: Record a violation → vehicle photo, Scan plate (read on the phone — or Photo only to skip reading), type → Save.“Saved on the phone.”
3Issue the fine: Print notice on the pocket printer — or Issue without printing if there is no printer.The printed notice: amount, offence code, due date.
4Home → Send to laptop by cable → save the pictures. Android: Save to this phone. iPhone: Save to Photos → Save Images.“Each ticket is one picture with its data in a code.”
5Plug in the USB cable. iPhone: unlock → Allow / Trust. Android: notification → USB → File transfer.“Only a cable.”
6Laptop: Receive from phone (Dashboard → Live feed) → Choose pictures from the phone.
7Windows: This PC → the phone → iPhone: Internal Storage › DCIM › newest folder. Android: Internal storage › Pictures › ParkPatrol. Select the new pictures (Ctrl+A is fine — other photos are skipped) → Open.
8Watch the list fill: Imported · Fine AED …. The ticket appears in the live feed marked By cable, with a pin on the map.“From the phone to the control room, by cable.”
9Click Open on a row.Photos, fine, officer, and the history line Received over USB cable.
10Optional: pick the same pictures again.“Already on this laptop” — never counted twice.
11Patrol: phone → Patrol → Start patrol. With Settings → GPS source → Demo, tap Demo: walk the route — the checkpoints tick off on the map (about 90 seconds). With real GPS they tick off as the guard walks. Then Finish patrol.“The route came from the control room as a code — no network.”
12Phone → Send to laptop by cable (the patrol report is a picture too) → laptop Receive from phone.Field Team → Patrol routes shows 4/4 checkpoints, finished …, by cable.

On a Mac, the browser cannot open the phone directly: copy the pictures off first (iPhone: Image Capture app; Android: Android File Transfer or OpenMTP), then drag them onto the Receive from phone panel.

4 · If something goes wrong

ProblemFix
The phone is not under This PCUse a data cable (some only charge). iPhone: unlock it, tap Allow/Trust, replug; make sure Apple Devices is installed. Android: notification → USB → File transfer.
iPhone share sheet has no Save ImagesClose it, press and hold each picture → Save to Photos, then tap I have saved them to Photos.
The iPhone's DCIM folder is emptyWait a few seconds and reopen it; keep the iPhone unlocked.
The file window cannot open the phoneIn File Explorer copy the pictures to the Desktop, then drag them onto the Receive from phone panel.
The plate is not readTake the plate photo anyway (Photo only, or the shutter → Use photo) and type the number — or save without it: the plate photo goes with the ticket and the control room reads it. The reader works offline; it needs a sharp, straight-on photo of the plate.
The printer does not printPrinter on and charged, paired in Android Settings → Bluetooth (PIN 0000 or 1234), chosen in Park Patrol → Settings → Fine printer, and not connected to another phone or app at the same time. Try Test print. Still nothing: switch the printer off and on, or use RawBT. No printer at hand: Issue without printing.
Prints blank or faintBlank: the roll is in back to front (thermal side must face the print head). Faint: set density level 3 (see The fine printer), or clean the print head.
“No ticket code found”The picture was cropped, edited or is a screenshot. Save it again from the app.
“… is not on this laptop's team list”That guard account is not on the laptop; the ticket is still imported under that name. guard1–guard4 are on both.
The dashboard does not openOpen http://localhost:4357 yourself. If the window says the port is in use, Park Patrol is already running — use that one.
The route code will not scanTap Take a photo of the code and photograph the laptop screen, filling the frame. Turn the screen brightness up. A code for another guard is refused — show the right guard's code.
Checkpoints do not tick offReal GPS: walk within the route's radius (40 m by default; set per route on the laptop), outdoors. Demo: Settings → GPS source → Demo, then Demo: walk the route. Or tap I'm at ….
Map shows circles, not streetsThis copy has no built-in map (the package normally includes Abu Dhabi). The patrol areas are drawn instead; pins and routes still work.

5 · Accounts and what this demo is

  • Laptop: supervisor or admin / Astrikos2026. Phones: guard1 … guard4 / Astrikos2026.
  • The laptop starts with sample tickets so the dashboard is not empty.
  • The Android app is signed for testing (installed directly, not from Google Play). It prints to a paired Bluetooth thermal printer (ESC/POS), through RawBT, the printer maker's app, or the Android print dialog — or issues the fine without paper.
  • This is a demo of the workflow. The production design — the laptop enrols each phone, signed transfer files, automatic copy when the cable is plugged in — is described in the project's OFFLINE-ARCHITECTURE.md.
